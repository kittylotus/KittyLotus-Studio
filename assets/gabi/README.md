# Gabrielle assets

`lounge.webp` is a TEMPORARY screenshot crop used as fallback in Overview and sidebar.

For full-quality artwork, save the original at **`lounge-full.png`** (PNG). Studio automatically replaces both instances when the file exists. No code edit needed. The new full image shared inline in chat was not available as a raw attachment in this build; don't re-crop it from a screenshot.

`expressions/` bundles 15 originals from the user-provided archive.

You can preview a new lounge image from Gabi Gallery. Session previews aren't committed. To publish the original, place it in this directory and publish with GitHub Desktop.

Current Studio Overview lounge artwork: `gabi-views.webp`, supplied in Gabi-Views.zip. The old `lounge-full.png` placeholder is no longer required. The bundled `lounge.webp` is retained as a historical asset/fallback only.
